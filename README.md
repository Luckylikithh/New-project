CUBE Prototype

Overview

CUBE is an e-commerce platform designed to enhance online shopping by offering a virtual 3D fitting experience. It allows users to create customizable avatars using body-scanning technology, helping them visualize how clothes will fit their unique body shapes. By consolidating fashion brands in one place, CUBE aims to reduce sizing inconsistencies, minimize returns, and improve overall customer satisfaction.

This prototype was designed using Figma to showcase the core functionality and user experience of CUBE.
